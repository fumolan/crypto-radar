# 📡 加密雷达

> 1h/4h/24h/7d 四周期热点扫描 · 热点共性画像 · 打开即实时提示

**在线使用**: https://fumolan.github.io/crypto-radar/

- **四周期热点榜**: 币安 1小时/4小时/24小时/7天 滚动窗口涨跌幅, 热度=四周期百分位均值, 点表头按任一周期排序
- **结构标签**: 四周期共振(趋势加速) / 短周期启动(新启动) / 趋势回调(中继) / 超跌反弹
- **共性画像**: 热点TOP20的结构分布·量能共性·加速特征·短线脉冲·双所印证
- **币安**: 浏览器实时直连(默认60秒自动刷新, 可调)
- **OKX**: 优先浏览器实时直连; 网络不通时自动降级 GitHub Actions 每10分钟快照(页面标注快照时间)
- **双所共振**: 同一币种同时进入两所涨幅榜或跌幅榜 → 资金共识最强, 顶部高亮显示两所各自涨幅
- 过滤: 24h成交额>$1M, 剔除稳定币/杠杆币
- **点击任意币种** → 跳转[开仓](https://fumolan.github.io/kaicang/)做信号/大墙/透视分析并模拟开仓
